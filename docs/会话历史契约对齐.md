# 原生 UI 无法进入会话：历史契约没对齐

## 现象

官方 Web UI 正常对话，但原生 Compose 界面打开会话后是空的（"无法进入会话"）。

## 根因：`session.history` 的返回形状与上层读取方式不一致

UI 侧读取方式（`ChatActivity.loadSessionHistory` + `SessionLog.fromHistory`）：

```kotlin
val envelopes = v?.optJSONArray("events")?.let { arr ->
    (0 until arr.length()).mapNotNull { arr.optJSONObject(it) }
} ?: emptyList()
val log = SessionLog.fromHistory(envelopes)
```

```kotlin
// SessionLog.fromHistory
val raw = events.mapNotNull { it.optJSONObject("event") }   // ← 期望每条是带 event 外壳的记录
```

```kotlin
// 会话实时配置/统计
val projValues = v?.optJSONObject("projections")?.optJSONObject("values")
val stats = projValues?.optJSONObject("sessionStats")
val ctxPressure = projValues?.optJSONObject("contextPressure")
val permissions = projValues?.optJSONObject("permissions")
```

而 `DshClient.syntheticSessionHistory`（我用一次性 `session/follow` 快照实现的历史取数）
把快照 **剥壳** 后又 **丢掉了 projections**：

| UI 期望 | 实际返回 | 后果 |
|---|---|---|
| `events[i] = {"type":"event","event":{…}}` | 裸事件对象 `{type:"turn/start",…}` | `optJSONObject("event")` 全为 null → 历史解析落空 → 会话空白 |
| `projections = {asOfSeq, values:{sessionStats,contextPressure,permissions,tokenUsage,…}}` | 无此字段 | 状态栏/上下文占比/消费统计全空 |

## 修复

`dsh ≥ 0.1.5` 的 follow 快照本来就是 UI 想要的形状，原样透传即可：

- `events` 直接放**记录本身**（`{"type":"event","event":{…}}`），不再剥壳；
- 透传 `projections`、`cursor`、`header`、`sessionId`。

`ApiCompat.adaptResult` 里的同一处剥壳缺陷也一并修掉（当前是死代码，防止以后启用时再踩）。

## 实测确认（对真实后端）

```
snapshot.records 条数 = 3
records[0] 外壳字段 = [ 'type', 'event' ]        ← 正是 UI 需要的形状
records[0].event.type = permission/preset
projections 字段 = [ 'asOfSeq', 'values' ]
projections.values 键 = [
  'title','goal','tokenUsage','contextPressure','contextBreakdown',
  'sessionStats','turnOutline','agentPreset','subagentCatalog','subagentTiming',
  'subagent','permissions','modelSelection','sessionListMetadata','imageLimits'
]                                                 ← UI 需要的键全部在
```

## 教训

跨版本适配时，**"我返回的数据看起来对"不等于"上层读得到"**。
这次是外壳层级（多一层 / 少一层）和"附带的聚合字段"两处偏差，
两者都不会报错，只会表现为"界面空白"——所以必须对着**消费方的读取代码**逐字段核对，
而不是对着协议文档核对。
